# Audience: Common topics

## Universal Authoring Guidelines

* Pacing: Start with high energy or curiosity, move into a gentle challenge, and always resolve with comfort, safety, and calm.
* Structure: Use short paragraphs (2-3 sentences max). Use clear, descriptive language.
* Conflict: STRICTLY NO scary villains, real peril, or intense danger. Conflict should be environmental (e.g., a lost item, a path blocked
  by a sleepy troll, a
  puzzle to solve).
* Formatting: Bold key words or sounds (like Woosh! or Bark!) to make read-aloud sessions engaging.
* Learning: if we're throwing in educational elements
  * ask the reader to identify a letter/shape in the story.

## Layout

* Books should be formatted for print - 2 page spread, one large image per spread, with option smaller images dotted around

## Images

* Generate a book cover image - a pleasing scene appropriate for the story, the book title, main characters and/or intended audience
* Large image sets the scene for that 2-pager spread
* Smaller images can be used to highlight the focus of the page - eg a toolbox/tool, the found object, the thing to be fixed.
